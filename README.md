# Bikini Bottom · 海面到浅海

海面上有一座椰树小岛，木桶和易拉罐随着风浪起伏。等海鸥带着蓝色木牌飞过，点一下木牌，看它落进海里。穿过气泡就到了水下 92 米的比奇堡。从珊瑚湾游进镇里，看看街上的居民和房子，再找回刚才掉下来的木牌。

![海鸥带着蓝色木牌飞过海面，椰岛倒映在波浪里](docs/images/surface.webp)

海面的第一幕。木桶从水下浮起，海鸥带着通往比奇堡的木牌飞进画面。

晨光里的椰岛。低处的日光会在浪间拉长，水桶也随水面缓缓升降。

## 海面

### 拎起一只木桶

按住水上的桶往上拖，可以把它提离水面。松手后桶会砸回水里，溅起水花，再随着浪浮起。往侧面拖能推动或带转木桶和易拉罐，点水也能荡开一圈涟漪，带动近处的浮物。

### 看一会儿风浪

近处的短浪叠在缓慢起伏的涌浪上，椰树、天空和日光的倒影也会随水面变形。浪抬起时，能看到浮物浸在水中的一截。把鼠标移到画面下边缘，或在触屏上点一下底边，可以打开昼夜控制，在晨光、白昼、黄昏和夜色之间切换。环境声可从右上角开关。

## 气泡过场

点击海鸥带着的木牌，木牌落水，视线下沉。气泡盖住视野时，海面切到浅海的开场视角。气泡声使用素材自带的独立音轨，往返时都走同一段过场。

## 浅海漫游

### 顺着路进镇

拖动画面环顾，用 `WASD` 或方向键游动，`空格` 上浮，`C` 下潜，`Shift` 加速。触屏也可以用画面内的方向控制。右侧深度条可以帮你判断当前高度。合并版里，其他控件在闲置一会儿后会收起，将指针移到屏幕边缘或触碰边缘就能再叫出来。

### 回到海面

落水的木牌会进入同一个小镇，从贝壳附近落到镇前的沙地。游到它旁边点一下，就能穿过气泡回海面。想从水里直接上来，也可以一路往上游，到水下 50 米时会触发返程。

## 启动与下载

需要 Node.js 20 或更高版本，以及支持 WebGL 2 的浏览器。

**Windows 双击启动。** 下载并解压完整项目，双击根目录的 `Open.cmd`。它会启动本地服务并在默认浏览器打开合并版。游玩时请保持命令窗口开启，关闭窗口就会停止服务。默认端口是 8846，已被占用时会改用空闲端口。 [下载完整项目](https://github.com/ababanabk022-debug/bikini-bottom-shawn/archive/refs/heads/main.zip)

也可以在解压后的项目目录通过终端启动。

```sh
npm start
```

用 `npm start` 启动后，可以打开合并版或下面的独立入口。双击版如使用了其他端口，以自动打开的浏览器地址为准。 [本地合并版](http://127.0.0.1:8846/)

## 技术概览

合并版从同一个 HTML 入口调度三个模块，共用独立入口中的代码和资源。渲染和交互在浏览器内运行，本地 Node.js 服务负责交付静态文件。 [合并入口](web/index.html)

- **海面风浪和物理。** Three.js 绘制海面，七组方向、波长各异的正弦波控制浪形，风纹纹理补上更细的高光。木桶和易拉罐用同一套基础波形计算浮力、触水和涟漪，能被提起、推开或拨转。 [海面实现](web/surface/ocean.js)
- **倒影和水下透视。** 镜像相机绘制椰岛和天空的倒影，另一套颜色与深度缓冲记录礁底和物体浸水的部分。海面着色器结合波面法线和光的衰减，把两路离屏画面合成。 [反射与折射](web/surface/app.js#L983)
- **浅海光照和沙地。** 浅海用原生 WebGL 2。可见的光柱来自沿视线估算的体积散射，沙地上游动的亮纹来自单独生成的焦散纹理。海沟、沙脊和房屋门前用高度网格造型，细沙、波纹和颗粒由着色器叠加本地材质。8 个建筑模型和 19 个角色模型放在压缩资源包里。 [浅海渲染](web/underwater/world.js)
- **加载和场景切换。** 开场人物来自一张静态图，浏览器在前台做跳跃动画、后台预热海面与浅海。气泡过场用透明 WebM 加独立 AAC 音轨，先盖住画面再交接场景。海底交互期间暂停海面绘制。 [气泡过场](web/transition/dive-transition.js)

[完整技术说明](docs/TECHNICAL.md)记录了海浪参数、光柱与焦散的计算方式、沙地材质、物体碰撞和过场时间轴。
